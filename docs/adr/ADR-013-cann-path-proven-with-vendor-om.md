# ADR-013 · CANN 通路以厂商 `.om` 端到端验证通过；缺口收窄为"转换器"

- **状态**：已接受（2026-09-18）
- **前置**：ADR-012（CANN/NNRt 直连评估 → 当时结论"不换"，理由含"离线入口不收 `.ms`、终点未验证"）
- **后续**：若拿到 OMG 或做出在线构图映射器，本 ADR §「未完成动作」需要重开，届时应新建
  ADR-014 讨论"是否把 CANN 升为第四个后端"——**升后端要过 ADR-002 的保真方法学，不能只看车牌串**
- **证据**：`_evidence/A11-cann-om-end-to-end-20260918.md`、`_evidence/cann_om_run_20260918.log`、
  `_evidence/A10-cann-nnrt-probe-20260918.md`

## 问题

ADR-012 得出「CANN 通路可用但终点未验证，`.ms` 被拒」的结论。**被拒到底是"设备没打开这条路"，
还是"我们喂错了格式"？** 这个问题决定了后续要不要再投入。

## 决策

**认定 CANN/NNRt 通路为「已验证可用、当前不采用」**，并把缺口从"通路未知"改写为
"缺 `.om` 产出工具（OMG）"。

依据（同一探针、同一设备、同一次运行的对照，见 A11 §2）：

1. **一份厂商产出的真 `.om` 全绿跑通**：`compat=0` → `build_rc=0` → `executor=ok` →
   `run_rc=0`，并读出 IO 规格 `[1x3x227x227]` FP32 → `[1x1000x1x1]` FP32。
2. **同一批 `.ms` 仍被拒**：3/3 `compat=1` + `build_rc=1`。
   → 差别**只有文件格式**，所以之前的失败是**格式问题，不是权限/能力问题**。
3. **输出经完整性校验**：`out_sum=1.0005`（1000 维和为 1）→ 确为合法 softmax 分布，
   即 NPU 真的跑完了完整前向，而非仅返回成功码。
4. **拿到 CANN 侧第一个实测时延**：`run_ms_each=2.186|0.944|0.918`，稳态 **~0.92 ms**
   （首轮高出 ~1.27 ms 为首次调用开销）。

**为什么不立刻采用**：我们的三个模型都是 `.ms`，要进 CANN 必须先产出 `.om`，
而 OMG 需要华为开发者账号 + 64 位 Linux + 与设备 CANN `108.631.120.010` 版本对齐 —— 手上没有。
在拿到 `.om` 之前，`MindSpore Lite + NNRT delegate` 仍是唯一能跑通生产链的 NPU 路径
（且 A10 已证明它就是官方 NNRt 底座）。

## 本轮顺带确认的两条工程能力

- **显式设备绑定可用**（`OH_NNCompilation_SetDevice` 返回 0，设备 id 来自
  `OH_NNDevice_GetAllDevicesID`）→ 落点证据可以从"解析日志"升级为"代码里指定"。
  **这是本项目在落点证据上唯一还没用上的更硬手段。**
- **IO 规格运行时可读**（`OH_NNExecutor_CreateInputTensorDesc` +
  `OH_NNTensorDesc_GetName/GetDataType/GetShape`）→ 对接前后处理不必依赖模型文件。

## 边界声明

- 那份 `.om` 是**客人模型**（ImageNet 分类，来自官方公开 codelab），与车牌识别流水线无关；
  它**不进入**任何生产路径、性能表或论文数字。它的角色仅限机制证明。
- 输入是**合成确定性填充**（沿用 ADR-004 §3.4 的同一式），因此 `argmax=111` **不可解释**；
  本轮结论只覆盖**机制与时延**，不涉及精度。
- 只有**一份** `.om`，不能外推"所有 `.om` 都能跑"（`.om` 与 CANN 版本敏感相关）。
- 仅 3 次重复、无 thermal 标注 → **不构成基准**。

## 未完成动作

1. WSL2 + 开发者账号取 **OMG** → 转我们自己的模型 → 探针改一行验证三关
   （`compat` / `build_rc` / `run_rc`）。这是把 CANN 变成"第四后端"的最短路径。
2. 或走 NNRt **在线构图**（`OH_NNModel_AddTensor/AddOperation`），不依赖 `.om`，
   代价是自研算子映射（ONNX 节点 det 416 / rec 444 / cls 103）。
3. 真升为后端时，必须与 `ms-nnrt` 做**同输入 L2 对照**（ADR-002），并补 30 次 p50 + thermal 标注。
4. 论文口径：本轮可写「厂商离线模型格式的通路可用性验证」，**不得**写成「使用 CANN 加速了车牌识别」——
   因为被验证的模型不是车牌识别模型。
